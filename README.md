# carsonocker2_my_evr_repository
Graph Comparing Combined Groundfish Catch by Gear Type in the Bering Sea and Gulf of Alaska in 2025
By Carson Ocker

My repository contains data and code used to create a graph that shows the recorded catch of multiple groundfish in metric tons in the Bering Sea and Gulf of Alaska in 2027, sorting the catch by gear type. Groundfish catch data was collected by NOAA.

How the graph was made

1) Extract Catch Data

2) Organize data by location and gear type

3) Combine Data
